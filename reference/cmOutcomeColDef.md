# cmOutcomeColDef

List with column names for the cohort method outcome table

## Usage

``` r
cmOutcomeColDef(colNames)
```

## Arguments

- colNames:

  Optional a vector of column names to restrict to

## Value

A column definition list

## Details

Returns a names list with the cohorts names
