# getNegativeControlsFromJson

Extract cohorts from json

## Usage

``` r
getNegativeControlsFromJson(json)
```

## Arguments

- json:

  The json analysis specification

## Value

A data.frame with the negative control details or NULL if no negative
controls

## Details

Returns a names list with the cohorts
