# display a reactable when there are multiple outputs to print

display a reactable when there are multiple outputs to print

## Usage

``` r
tagPrint(x)
```

## Arguments

- x:

  The object, such as a reactable, to print

## Value

Nothing just prints the object in quarto

## Details

Wraps the input around print and shiny:tagList
