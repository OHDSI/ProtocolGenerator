# getFunctionFromArgName

This gets the input name from the arg name as CohortMethod ass Arg to
the inputs

## Usage

``` r
getFunctionFromArgName(package, argumentName)
```

## Arguments

- package:

  Name of installed R package of interest

- argumentName:

  Name of the input

## Value

the name of the input the setting arg corresponds to

## Details

Returns the name of the input the setting arg corresponds to
