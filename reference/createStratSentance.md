# createStratSentance

Create a sentence that explains the stratification defined in the
analysis.

## Usage

``` r
createStratSentance(CohortIncidenceModuleSettings)
```

## Arguments

- CohortIncidenceModuleSettings:

  The cohort incidence module specification

## Value

An string with the stratification information

## Details

Returns a string
