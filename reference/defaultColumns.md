# defaultColumns

create reactable colunn definition where if the column bold is TRUE or
NA the column value had red font otherwise black the bold column is then
hidden and column level2 had no name shown

## Usage

``` r
defaultColumns(data)
```

## Arguments

- data:

  the data.frame to use in reactable

## Value

Returns a reactable colunn definition

## Details

Returns a reactable colunn definition
